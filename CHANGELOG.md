# Changelog

## 1.0.0

First major release of the TEDDY-developed successor to [SPlayer-Next](https://github.com/SPlayer-Dev/SPlayer-Next).

- Refined desktop layout with a full player, dynamic background, adaptive themes, and live audio spectrum.
- Shazam-powered music recognition from system audio.
- Windows WASAPI exclusive playback with bit-perfect status and detailed output information.
- Word-by-word lyrics with TTML, QRC, JSON, LRC, YRC, KRC, LyS, SRT, and ASS support, plus desktop, Dynamic Island, and Windows taskbar views.
- Local library, playlists, metadata editing, downloads, and Subsonic, Jellyfin, and Emby streaming.
- System media controls, Last.fm scrobbling, Discord Rich Presence, plugins, and external control APIs.

Original project contributors retain credit for their work under AGPL-3.0.
